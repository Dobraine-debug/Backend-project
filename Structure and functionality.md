**Project structure and function**

The program is intended to simulate a system at a restaurant for handling data about customers, invoices, bookings, employees and schedules.

Included is a class named "SampleData" which will reset the database and fill it with test data. The usage of the class can be removed if the

user want to fill the database from scratch. The program is divided into three groups:



**Customer service**
Deals with data about customers as well as invoices connected to them.



**Employee service**
Deals with data about employees and their Schedules



**Booking service**
Deals with information about the tables in the restaurant, adding and removing reservations.
